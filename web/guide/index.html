为什么没有弹系统通知，或听不到声音？

灵动岛文字提醒无需系统通知权限。需要额外横幅时，在「设置 → 通知」主动开启 macOS 系统通知。声音在「设置 → 声音」调整，可分别试听完成、出错和需要输入的提示；检查主开关、音量、专注模式和安静时段。

点击后没有回到原会话？

Cursor 请确认桥接扩展已加载；Claude Code 请在接入后新开会话以捕获终端身份。Terminal / iTerm2 可能在首次定位时申请 macOS 自动化权限。无法确定目标时，小岛会说明原因，不猜测打开其他会话。旧终端记录不一定具备精确定位信息。

刘海屏和外接显示器都能用吗？

有刘海时避开摄像头区域，无刘海时显示顶部小条。在「设置 → 显示」选择屏幕、字号和尺寸。默认面板宽度为 640pt，可按需要调整。「刘海尺寸微调」在系统自动尺寸上增减，0 为自动；摄像头避让不变。也可在显示设置选择四种图标或导入本地 Logo；在工具接入页为每个来源设置独立颜色。

Windows 或 Linux 能使用吗？

当前 Agent Isle 客户端仅支持 macOS 14 或更新版本，Intel Mac 和 Apple Silicon Mac 使用同一安装包。Windows、Linux 需要单独的客户端适配，不能直接运行此压缩包。

这个网页会上传我的数据吗？

不会。页面由本机 127.0.0.1 上的临时服务器提供，只读取工具配置是否存在以及 Agent Isle Hook 是否已安装，不读取或展示对话正文。没有远程字体、分析脚本或账户服务。退出 Agent Isle 后服务器同时停止；下次可从应用菜单重新打开指引。

如何卸载？

先在「设置 → 工具接入」移除 Agent Isle 接入，再退出并将应用移到废纸篓。原始 AI 对话不受影响。需要保留个人设置时，保留用户资源库中的 Agent Isle 数据目录。
