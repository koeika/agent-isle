三、功能与边界
• 可自行选择监听 Codex、Claude Code、Cursor、DS Harness；默认开启 Codex 和 Claude Code，Cursor 与 DS Harness 默认关闭，须主动勾选。取消勾选的工具不再监听、显示、计数或提醒，但保留已有接入配置。
• 完成、需要输入和错误状态可提供不同提示音及单行提醒；系统横幅需另行授权，提示音受音量、静音及安静时段等设置影响。状态准确性依赖原工具记录或 Hook 事件，不是对“所有本机 AI 软件、所有会话”的无限制监听。
• 对 Codex、Cursor、Claude Code，点按可按条件尝试返回对应会话或终端标签。能否精确定位取决于工具版本、桥接是否加载、会话身份和系统权限；旧会话、已关闭窗口或缺少终端身份时可能无法定位。原生 Terminal / iTerm2 的精确定位尚待更多实机验证，不作为默认保证项。
• DS Harness 支持本机已知 v4 格式的主会话记录（最近七天），包含 JSONL / 多帧 Zstandard；不包括子 Agent、远程主机及任意其他格式。勾选后无需安装 Hook；解码压缩日志需已安装的 DeepSeek Harness 桌面运行环境或具备 zstd API 的 Node，不能据此承诺所有自定义安装和未来版本兼容。当前点按仅打开 DS Harness 应用，不会自动定位具体聊天；可右键查看最近对话快照。要求精确跳转 DS Harness 聊天的用户，请勿将本版视为已具备该能力。
• 支持悬停展开、移出收起、快捷键切换、来源颜色和本地 Logo 等设置。无刘海显示器呈现顶部紧凑条；不同屏幕、缩放和系统版本下外观可能不同。
• “最近对话”提供最近消息快照，并非完整历史管理、云同步、聊天备份或数据恢复工具。
• 本服务不包含 Vibe Island 授权、破解、去付费限制或其官方售后。Agent Isle 是独立实现的软件。
• 宣传图如标注“界面示意”，仅用于解释交互。实际交付以订单约定版本及验收结果为准；宣传与约定的具体功能仍应真实履行。
