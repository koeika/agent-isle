把多个工具的会话状态放在屏幕顶部：完成了、出错了、需要你输入时，一眼看见。

【能帮你做什么】
1. 统一查看四种工具：Codex、Claude Code、Cursor、DS Harness。
   按需勾选监听，默认启用 Codex、Claude Code；Cursor 和 DS Harness 默认关闭。订单需明确具体接入哪些工具，不默认提供四种工具的全部服务。
2. 及时接手：任务完成、需要输入和出错有不同状态、提示音和单行提醒。收起时不自动展开整张列表。
3. 少切窗口：Codex、Cursor、Claude Code 可按接入与身份条件尝试跳到对应会话或终端；DS Harness 当前只打开应用，不定位具体聊天。
4. 了解上下文：显示最近用户提问、工具活动和回复摘要；可查看最近对话快照。不是完整历史浏览、备份或恢复工具。
5. 用顺手的样子：悬停展开、移出收起、Ctrl+G 快捷切换；四种预设像素图标、自定义本地 Logo、独立来源颜色、音量和安静时段。
6. 完成有已读：成功定位完成会话，或查看最近对话后清除未读；同一会话下轮完成再次提醒。只打开 DS Harness 应用不会冒充“已查看对应聊天”。

【四个来源，接入方式不同】
Codex：读取本机会话索引和记录，无需安装 Hook。
Claude Code：准确生命周期提醒依赖 Hook；原终端定位依赖终端身份及系统权限。
Cursor：准确生命周期提醒依赖 Hook，精确聊天/集成终端选择依赖桥接扩展；配置后通常需重启或重新加载窗口。
DS Harness：无需 Hook，只读本机已知 v4 格式的主会话日志（最近七天），支持 JSONL / 多帧 Zstandard，排除子 Agent。压缩日志需已安装的 DeepSeek Harness 桌面运行环境，或支持 zstd API 的 Node。当前跳转只打开应用，不能定位具体聊天。

【你的数据放在哪里】
Agent Isle 监听和快照保存在本机，无账户、遥测或云端对话上传。会话快照可能包含对话内容，请妥善保管。AI 工具自身的模型调用、网络连接与数据处理，仍受各工具自己的政策约束；“本机监听”不表示 AI 模型离线运行。

【适用设备，购买前必看】
• macOS 14 或更新版本；Apple Silicon / Intel 通用二进制，目前主要实测 Apple Silicon。Intel 或特殊版本组合请先咨询。
• Windows、Linux、手机和平板暂不支持。无刘海 Mac 使用顶部紧凑条，也能使用；外观受屏幕和缩放设置影响。
• 分享版未经过 Apple Developer ID 公证，可能出现开发者验证提示。单位受管 Mac 请先确认允许安装与所需接入权限；不要求关闭系统安全保护。
• 软件提供状态与跳转辅助，不生成 AI 回答、不加速模型，不保证工具任务成功。第三方未来更新可能影响兼容性。
• 原生 Terminal / iTerm2 精确定位尚待更多实机验证；不是所有旧会话、所有终端或所有 AI 线程都能精确定位。
