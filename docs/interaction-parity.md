# Agent Isle 交互对照（Vibe Island 1.0.42）

范围由用户明确为：交互与设置布局对齐；业务保留本机 Codex、Cursor、Claude Code。参考来源是原版实际 UI、可访问性树与原版自身日志，不使用其代码、图像、音频或许可机制。

## 主面板

| 实际观察的原版行为 | Agent Isle 实现 |
| --- | --- |
| 悬停约 0.15 秒展开 | 可调 0.05–1 秒，默认 0.15 秒 |
| 鼠标移出后收起；日志记录约 0.26 秒 | 0.28 秒离开宽限，点击展开不自动固定 |
| Esc 收起；避免指针仍停留时立刻重开 | 收起后须实际移出再移入 |
| 卡片按项目、标题、provider、消息、工具活动排列 | 同样的紧凑行层次；保留外部 CLI / 归档来源提示 |
| 鼠标经过卡片不会驱动滚动 | 只有键盘选择才自动滚动；操作期间冻结行顺序，状态继续实时更新 |
| 点击会话跳转；可禁用点击跳转 | 现有精确跳转；右键显式跳转、最近对话、复制 ID / 回复、项目定位 |
| 卡片右键过滤目录 / 消息 | 目录包含、消息前缀、消息包含；实时匹配数量；规则可停用与移除 |
| 音量图标与设置齿轮位于上方 | 紧凑工具栏；设置打开独立窗口，不锁住灵动岛 |
| 完成 / 错误自动展开并定时收起 | **用户要求优先**：折叠时仅单行提示；5 秒默认，可调 2/3/5/8/10/15 秒 |
| 需要批准 / 输入提示 | **用户要求优先**：橙色单行保持至已回答；工具继续运行不能盖掉 |
| 输入优先于普通完成提示 | 保留现有优先队列；预览不覆盖真实待输入提醒 |
| 自动提醒可点击外部提前关闭 | 可选；Esc、自动停留时间分别控制 |
| Clean / Detailed 显示 | 简洁数字 / 详细当前活动；始终避让实际摄像头区域 |
| 自适应展开高度和最大宽高 | 根据行数变化，高度上限 520pt，默认宽度 **640pt**（保留用户此前确认） |
| 全屏隐藏、空闲隐藏 | 可配置；全屏只读取公开窗口几何元数据；仍可显式调用切换器 |
| 智能抑制 | Cursor 桥接确认当前窗口聚焦、原聊天已选中时抑制悬停；未知目标保守展开，不猜测其他应用的焦点 |

## 独立设置窗口

650 × 680pt 固定窗口，遵循系统明暗模式；左侧彩色图标分组，右侧标题、圆角分组、原生开关 / 菜单 / 滑条 / 重置。主面板始终为黑色。原版的菜单栏 Settings… 与 Cmd+, 入口也保留。

| 页 | 当前功能 |
| --- | --- |
| 通用 | 登录启动（只在用户主动打开时注册）、悬停和时长、智能抑制、全屏 / 空闲隐藏、离开收起、提醒停留、外部点击、闲置清理、点击跳转 |
| 工具接入 | 当前三个工具状态说明、安装 / 修复 Hook 与 Cursor 桥接、移除确认、重新连接；不改工具审批策略 |
| 通知 | 单行提醒开关、系统通知授权、真实效果预览、手动专注模式、锁屏 / 睡眠静默、自定义过滤与实时预览 |
| 显示 | 简洁 / 详细、显示器、10–13pt 字号、行高、最大宽高、项目名称、活动详情、卡片预览、刘海尺寸增量调整、实时实际尺寸与重置；四种图标和本地自定义Logo |
| 声音 | 主开关、保留用户 85% 音量、三种真实事件分别选音 / 试听、系统声音子菜单、导入本地音频（≤10MB）、跨午夜安静时段 |
| 快捷键 | 默认 Ctrl+G；轻按打开、上下选择、Enter 跳转、重复循环、松开修饰键跳转、Shift 反向、数字提示与 1–9 跳转、修饰键选择、按键录制、禁用；注册冲突明确显示 |
| 关于 | 版本、真实免费 / 无遥测说明、匿名诊断导出、维护入口、致谢与退出 |
| 用量 / SSH / 实验 | 保留侧栏布局位置，明确当前版本范围；没有无效开关、收费、远程主机或自动审批 |

## 原版能力的范围映射

原版的账户配额 / 用量提供商、Pass 激活付费、SSH / Docker 远程安装、Beta 自动更新、遥测、Agent 自动放行 / Bypass、子代理团队展示、未接入 CLI 分支不属于本次约定业务范围。没有用样式相似的开关伪装这些能力。

系统 Focus 状态、录屏 / 共享识别没有稳定的无额外权限公共接口，当前使用可控的应用专注开关与实际锁屏 / 睡眠信号；不声称自动读取系统勿扰状态。没有实现未被监听器识别的开始、上下文上限、spam 等声音事件。

## 验证

每次运行的结果在 `~/Library/Logs/Agent Isle/validation/2026-11-05-interactions/`。纯状态机测试不能代替真实鼠标悬停，设置截图不能代替设置保存；二者分开记录。无法执行的原生边界必须保留为未验证，不写成全部完成。
